# 🍒 Cherry Proxy Lite для Lampa

Это быстрый и бесплатный персональный прокси на базе Cloudflare Workers для обхода блокировок балансеров в приложении Lampa. 

Вам не нужны навыки программирования, консоли или программы-установщики. Всё делается прямо в браузере за 3 минуты.

---

## 🛠 Шаг 1. Регистрация и создание Worker'а

Для работы нам потребуется бесплатный аккаунт Cloudflare.

1. Зарегистрируйтесь на сайте [Cloudflare](https://dash.cloudflare.com/sign-up) (если у вас еще нет аккаунта).
2. В левом меню нажмите на раздел **Workers & Pages**.
3. Нажмите синюю кнопку **Create** (или *Create application*), а затем выберите **Create Worker**.
4. В поле *Name* впишите любое название английскими буквами (например, `lampa-proxy`).
5. Нажмите кнопку **Deploy** в правом нижнем углу. (Cloudflare создаст базовый шаблон, это нормально).

---

## 💻 Шаг 2. Загрузка кода Cherry Proxy

Теперь нам нужно заменить базовый шаблон на наш код.

1. Сразу после успешного создания (Deploy) нажмите кнопку **Edit code**. У вас откроется редактор кода.
2. В левой части экрана **удалите весь текст**, который там написан.
3. Откройте файл `worker.js` в [нашем репозитории (ссылка)] и скопируйте весь его код.
4. Вставьте скопированный код в пустое окно редактора Cloudflare.
5. В правом верхнем углу нажмите синюю кнопку **Deploy** (и подтвердите сохранение).

---

## 🔐 Шаг 3. Установка личного пароля

Чтобы никто чужой не смог пользоваться вашим прокси, нужно задать пароль. В коде воркера он называется `PROXY_KEY`.

1. Вернитесь на главную страницу вашего воркера (нажмите на его название `lampa-proxy` вверху слева или стрелочку "Назад").
2. Перейдите на вкладку **Settings** (Настройки).
3. В левом меню настроек выберите раздел **Variables and Secrets** (Переменные и секреты).
4. В блоке *Environment Variables* нажмите **Add variable** (Добавить переменную).
5. Заполните два поля:
   * **Variable name**: `PROXY_KEY` *(Обязательно большими буквами, без пробелов)*.
   * **Value**: Придумайте любой цифровой пароль (например, `12345678`). Этот пароль вам будет удобно вводить с пульта телевизора.
6. Нажмите кнопку **Deploy** (или *Save and deploy*), чтобы сохранить настройки.

> 🔗 **Скопируйте ваш адрес:** Теперь перейдите на вкладку **Deployments** (или на главную страницу воркера) и найдите ссылку в разделе *Domains & Routes*. Она будет выглядеть примерно так: `https://lampa-proxy.ваше-имя.workers.dev`. Сохраните её и ваш пароль — они нужны для Лампы!

---

## 📺 Шаг 4. Подключение прокси в Lampa

Осталось только указать Лампе, что нужно использовать ваш новый личный сервер.

1. Откройте приложение Lampa на вашем телевизоре, приставке или ПК.
2. Перейдите в **Настройки** ➔ **Расширения**.
3. Нажмите **Добавить плагин** и введите ссылку на плагин подключения прокси:
   👉 `https://raw.githubusercontent.com/.../lampa-plugin.js` *(Замените эту ссылку на актуальный адрес вашего второго JS-файла для Лампы)*
4. Обязательно **перезагрузите** приложение Lampa.
5. Перейдите в **Настройки** ➔ **Прокси** (появится новый раздел от плагина).
6. Введите ваши данные:
   * **Адрес прокси**: Ваша ссылка на Cloudflare Worker (например, `https://lampa-proxy.ваше-имя.workers.dev`).
   * **Пароль**: Ваш цифровой пароль, который вы придумали на Шаге 3 (в поле *Value*).
7. Сохраните настройки.

🎉 **Готово!** Ваш личный прокси-сервер настроен и защищен. Теперь балансеры в Лампе будут работать стабильно и без блокировок.
